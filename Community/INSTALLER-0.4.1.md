# DOT MIC 0.4.1

アプリ配置と通常ZIPの配布方式を更新します。既存の公開 Release・タグ・ZIPは置き換えません。

## 配布と導入

- `DOT MIC 0.4.1.zip` は複数ファイルの通常ZIPです。ペイロードを1つのEXEに埋め込みません。
- UIとSetupの.NETランタイムを `内部ファイル/UI` で共有し、重複ファイルを減らします。
- ZIP全体を展開して `セットアップ.exe` を起動します。既定のアプリ保存先は `%ProgramFiles%\DOT MIC\Application`。同意画面で専用のローカル保存先とデスクトップショートカットの有無を選べます。
- ダウンロード先からファイルを移動・削除せず、保護された保管場所に準備してから導入先へコピーします。導入後はダウンロードしたZIP・展開フォルダーを削除できます。
- 通常UIは管理者権限不要。修復・削除・復旧は導入先の `セットアップ.exe` を明示的に起動します。ショートカットは全ユーザーのデスクトップが対象です。
- 一般ユーザーが置き換えられる親フォルダー、ネットワーク、Windows・音声・復旧用の保存先は拒否します。親フォルダーの権限を緩和しません。
- APO配置先とバックエンド契約は `0.4.0-community` のままです。APO・モデル・既存ネイティブDLLを再ビルドしません。
- アプリ配置は所有ファイル一覧・バックアップ・ステージング記録を保持します。削除は記録されたハッシュと一致するファイルのみ。変更されたファイルを残し、空の所有ディレクトリのみ後片付けします。
- 自己削除はSetup終了後に保護キャッシュから実行します。削除待ちの記録・完了確認を永続化し、音声・登録・権限の復旧が未完了ならアプリだけの完了処理を拒否します。

## ZIPの作成

Windows x64、.NET 10 SDK、Visual Studio 2019 C++ Build Tools、Windows SDK 10.0.19041.0、CMakeが必要です。元の公開配布を展開した、ハッシュ一致済みのベースを指定してください。

```powershell
./Community/package-install.ps1 -BaseDirectory <展開済み0.4.0-community> -OutputDirectory artifacts/install-0.4.1-new
```

出力先は新規フォルダーのみ。`DOT MIC 0.4.1.zip`、`package-result.json` とビルド中間ファイルを生成します。公開版の `source-build.ps1`／`package-ux.ps1` の既存動作は変更しません。

## 確認範囲

- ビルド、表示・パス・旧レシート・削除／復旧状態判定のテスト。
- 本番のShown処理やネイティブ列挙を動かさないオフスクリーン同意画面の確認（幅480／424）。
- ユーザー許可済みの管理者ファイルテスト：専用GUIDフォルダーで配置・復元・中断ステージ・移動失敗／再試行・変更ファイル保持・削除完了確認／再利用・古い削除記録の拒否。ショートカットはテストフォルダー内のみ。
- ZIPとマニフェストの全ファイル一致、固定APO14ファイル・モデル・ネイティブDLLのハッシュ、ライセンス、安全説明、秘密情報・ローカルパスの監査。
- 共有ランタイムによるUI smoke起動。サインイン登録を変更せず、ライブ音声受入ではありません。

実際の導入／カスタム保存先への本番配置／デスクトップ作成／インストール済みSetupの終了後処理を一連で実行する確認は未実施です。音声・サービス・実デスクトップを変更するテストは今回の許可範囲外です。従来のDSP／音声受入を再利用し、Discord・NC・性能・再起動・導入削除の再試験はしていません。

配布ファイルのハッシュと確認範囲は0.4.1のRelease notesを参照してください。作業用の詳細記録は `artifacts` 内に保持します。解凍時間は同じPC・ディスクでの単発ローカル測定であり、ダウンロード速度や他環境の保証ではありません。
