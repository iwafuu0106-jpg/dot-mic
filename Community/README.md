# DOT MIC 0.4.0-community-ux1

1. ZIP全体を展開します。
2. 直下の`セットアップ.exe`でマイクを選び、「同意して導入」を押します。
3. 同じ場所の`DOT MIC.exe`を通常権限で開きます。

新しい導入の初期値：バイパス無効・音量補正 0 dB・ゲート無効・ノイズ除去無効。
サインイン時の起動は初回のアプリ起動時に有効になります。メニューで無効にできます。
Discordでは従来の物理マイクを選択します。

`内部ファイル`フォルダーは移動・削除しないでください。導入・修復・削除・復旧には管理者権限が必要です。通常利用に管理者権限は不要です。

Microsoft認証／WHQL版ではありません。未署名APOのため保護音声の互換設定を変更する場合があり、一部の著作権保護コンテンツの再生へ影響する可能性があります。変更内容は導入前に表示します。詳細は`SECURITY.md`、第三者ライセンスは`licenses/`にあります。

本更新は配置・表示・初期設定の変更です。APO、DPDFNet2 model、推論用DLL、ネイティブ統合用DLLは既存の受入済みファイルをそのまま使用します。導入・復旧データの形式と固定配置先は`0.4.0-community`を維持します。旧Releaseは保持します。
